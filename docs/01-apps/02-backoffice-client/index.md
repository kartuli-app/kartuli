# Backoffice Client

`apps/backoffice-client` is a Next.js app, with development port 3001 and an `/en` route. Its intended role is collaborator content management; the scaffold is not evidence of a completed editor or authorization system.

Use [Engineering](../../05-engineering/index.md) for workspace conventions, [Design System](../../04-design-system/index.md) for shared styling, and [Deployment](../../07-platform/02-deployment.md) for the configured Vercel deployment path. Authentication and authorization remain [Security](../../08-security/index.md) concerns requiring design before privileged workflows are introduced.
